# I18N.md — translatable text

The app renders every string through a key, and a locale catalogue answers that
key. English is a catalogue like any other, and it is the fallback every locale
falls through to.

## The rules

1. **A key is a path, never the English.** `t("common.save")`, never
   `t("Save")`. The namespace comes from where the string is rendered
   (`<feature>.<area>`, `layout.*`, `components.*`, `app`), the leaf from what
   it says. Correcting a wording changes a value, not a key.
2. **A key must exist in the English catalogue before it renders.** A key with
   no entry there is a defect, and the drift test names it. The only exception
   is user-authored text, which passes its own value as the fallback argument.
3. **The catalogue has two halves.** The `content.*` half is **generated** from
   the registries and never hand-edited — each key is built from the id the
   entity already carries. Every other key is **authored**: the generator adds
   the key set, a human writes the English.
4. **Every user-visible string goes through `t()`.** A literal that reaches the
   DOM untranslated is a defect, including one built by a helper or held in a
   key map. A constant holding keys is named for keys, not for labels.
5. **Shared words live under `common.*`.** One English string used under two
   different top-level namespaces gets one `common.*` key that every call site
   uses. A test enforces it.
6. **Only rendering goes through `t()`.** Comparison, lookup and storage keep
   the English they already store — a stored tier string, a saved slot name, a
   map keyed by a display name. If you cannot tell whether a string is rendered
   or compared, it is compared.
7. **A locale is a `Locale` union member plus its catalogue.** Nothing else
   branches on locale, and no engine path, storage key or test may. An empty
   value means untranslated and renders the English, never blank.
8. **Interpolate outside `t()`.** A key built by interpolation is translatable
   only where the collector enumerates every string it can produce; unless it
   does, pass a fixed key and compose the number around the call.
9. Chinese stays out of `src/` and `tests/` — CLAUDE.md § "Language".

Renaming a locale's own union member is a storage change and needs a migration;
adding one is not, because an unknown stored value already falls back.

## What makes a key reachable

The extractor reads two sources and neither is authoritative over the other:

- **UI keys** — string literals reaching `t()` in `src/`, directly or through a
  module-level key map or a helper's `return`, plus display-shaped properties of
  object literals under `src/ui/**`.
- **Content keys** — built from the registries by importing them.

A key reachable through neither is invisible to the catalogue and renders as
itself. That is the one failure the drift test cannot report, so a new key map
goes at **module scope** and the value passed to `t()` is the map lookup or the
helper call itself, never a local variable holding its result.
